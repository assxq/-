## 6. 사운드 (v2)
`audio/E01_audio_temp_mix.wav`는 **합성음 임시 믹스**다. v1(단순한 노이즈와 사인파)에서 다음을 바꿨다.
- 기계음을 **층으로 쌓아** 다시 만들었다 (플라스틱 딱 + 몸통 울림 + 스프링 잔향, 슬라이드는 끊겼다 걸리는 마찰)
- **작은 금속 방의 잔향**을 모든 효과음에 입혔다
- 패드는 사인파 대신 **톱니파 여러 겹 + 필터가 천천히 열리는 움직임 + 테이프 워블/플러터 + 포화**
- 정지할 때 소리가 끊기는 대신 **진짜 테이프 정지**: 모터음과 히스의 **피치가 떨어지며** 사라진다
- 11.0초 **드롭아웃 글리치**와 0.0초 **전원 인가 쿵**을 소리로 구현 (글리치 3번 계획과 일치)
- 좌우 위치: 헤드셋 소리는 화면 왼쪽으로 살짝 치우침. 방 소리는 좌우를 다르게 만들어 넓게 들린다
- **-16 LUFS**로 맞추고 피크를 -1.5dB 아래로 눌렀다 (v1은 -20.7 LUFS로 폰에서 묻힐 수준이었다)

| 시간 | 소리 | 파일 / 스템 |
|---|---|---|
| 0.00 | 전원 인가 쿵 + 짧은 워밍업 소리, 재생 키 | `sfx_poweron`, `sfx_key` |
| 0.0, 1.6, 3.2 … | REC 램프 릴레이 틱 (깜빡임마다) | `sfx_relay` |
| 0.3→4.0 | 방 소리와 모터 험이 먼저, 테이프 히스가 서서히 올라옴 | `stem_room`, `stem_tape` |
| 자막 타자 때마다 | 글자당 아주 작은 틱 (3가지 변형을 섞음) | `sfx_type` |
| 6.5 | 헤드셋 플라스틱 마찰 | `sfx_scrape` |
| 9.2 | 카세트 슬라이드 + 끝에서 안착하는 소리 | `sfx_slide` |
| 10.6 | 도어: 둔한 쿵 + 딸깍 + 래치 + 잔떨림 | `sfx_thunk` |
| 10.8 | 릴 회전 시작 (이후 계속) | `stem_tape` |
| 11.0 | **드롭아웃**: 0.1초 소리가 꺼지고 피치가 살짝 내려감 | `stem_tape`, `sfx_glitch` |
| 12.0→16.8 | 패드 (A2·E3·A3·C4). **웹페이지 송신 장면과 같은 화음** | `stem_pad` |
| 14.2 | 아주 작은 숨소리 (S5의 "작게 내쉼"). 선택 사항 | `sfx_breath` |
| 16.0 | 손이 데크에 닿는 소리 (이때 모터 험이 3dB 줄었다 돌아옴) | `sfx_hand` |
| 18.3 | 정지 키 + **테이프 정지** (피치 하강) + 릴 감속 | `sfx_key`, `sfx_spindown` |
| 19.0~20.0 | 방 소리만 남음 | `stem_room` |

### 스템 사용법
- 편집 툴에 **스템 4개를 따로 올려** 놓고 균형을 맞춘다. (`stem_sfx`가 너무 크다면 그것만 내리면 된다)
- 실제 폴리 사운드를 구했다면 `stem_sfx`를 **끄거나 −6dB 이하로 낮추고** 실제 소리를 얹는다. 방 소리·테이프·패드는 그대로 두면 질감이 이어진다.
- 합성 사운드와 실제 소리가 섞이는 구간은 **슬라이드(9.2), 문(10.6), 손(16.0)** 세 곳이 가장 효과가 크다.

### 소리 조정: "이렇게 들리면 이렇게"
`production/tools/make_audio_E01.py` 상단의 `MIX` 숫자를 고치고 `python3 production/tools/make_audio_E01.py`를 실행한다. (숫자는 dB, 클수록 크다. 마지막에 -16 LUFS로 다시 맞춰진다)
| 들리는 느낌 | 조정 |
|---|---|
| 히스가 지글거려 거슬린다 | `hiss` −37 → −41 |
| 전체가 너무 어둡다/답답하다 | `hiss` 올리기, 또는 `lowpass(out, 5500)`의 5500을 8000으로 |
| 기계음(슬라이드·문·손)이 너무 튄다/묻힌다 | `slide`, `thunk`, `hand`, `scrape`를 ±3 |
| 패드가 거슬린다/안 들린다 | `pad` −23 → −27 / −20 |
| 공간이 너무 울린다/건조하다 | `reverb_wet` 0.22 → 0.1 / 0.35 |
| 숨소리가 어색하다 | 파일 위쪽의 `BREATH = False` |
| 전체 음량 | `TARGET_LUFS` (기본 −16) |
**말로 알려 주셔도 된다.** "13초쯤 소리가 답답하다", "문 소리가 가볍다"처럼 말씀해 주시면 위 숫자와 합성 방식을 같이 고쳐 드린다.

### 검증한 것과 못 한 것
- 한 것: 통합 음량(-16.0 LUFS), 피크(-1.4dB), 구간별 음량, 각 효과음이 바닥 소리에 묻히지 않는지(이벤트 대 나머지 비율), 정지 시 모터음 피치 하강(58Hz → 26Hz), 드롭아웃 깊이(약 5dB), 패드 등장 곡선, 클리핑·DC 오프셋 없음. `E01_audio_timeline.png`에서 각 이벤트의 위치를 눈으로 확인할 수 있다.
- **못 한 것: 실제로 들어 보는 것.** 합성음이 귀에 자연스러운지는 직접 들어 보셔야 알 수 있다. 가장 어색하게 들릴 만한 곳은 **패드(12~19초)**와 **숨소리(14.2)**다.

**음악**: 별도 배경 음악이나 유행 음원은 쓰지 않고 원본 오디오로 올린다. 세계관의 소리는 모두 테이프의 소리여야 한다.

## 10. 문제 해결
| 증상 | 해결 |
|---|---|
| 얼굴이 클립마다 달라진다 | 시작 프레임을 항상 `mia_base_A.png`로 지정, 클립을 3초로 줄이기, 테이프 드롭아웃 글리치로 깨진 프레임을 가리기 |
| 입이 움직인다 | 네거티브에 `talking, lip sync`, 프롬프트에 `mouth closed` 반복, 안 되면 해당 구간을 정지 이미지 + 푸시인으로 대체 |
| 손이 이상하다 | 손 대신 소품 클로즈업 컷, 또는 손이 프레임 가장자리에 걸치게 구도 변경 |
| 움직임이 너무 크다 | 모션 강도(있다면)를 낮추고 프롬프트에 `very subtle`, `barely moving` 추가 |
| 자막이 안 읽힌다 | `caption_*.png`의 어두운 띠를 그대로 쓰고, 오버레이 위에는 질감 필터를 걸지 않는다 |
| 소리가 너무 가짜 같다 | 합성음을 −6dB 낮추고 실제 소리를 겹친다 |
