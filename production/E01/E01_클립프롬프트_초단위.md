# E01 영상 클립 초단위 설계서

> 목표: AI 영상 클립 4개 + 정지 이미지 + 편집 효과를 **프레임 단위로 맞물려** 20초짜리 완성본 하나를 만든다.
> 이 문서의 모든 시각은 **타임라인 시간 `t`(초)**, **프레임 `f`(24fps)**, **클립 시간 `c`(초, 생성된 클립 안의 시간)**로 적는다.
> `AI 영상 생성기`는 정확한 초 단위 연기를 보장하지 못한다. 그래서 이 문서는 **(1) 의도한 비트를 정확히 적고, (2) 모델에는 단순하고 안전한 지시를 주고, (3) 정확한 타이밍은 편집에서 맞추는** 3단 구조로 쓰였다.
> 확인용 움직이는 콘티: `animatic/E01_animatic_labeled.mp4` (이 문서의 타이밍을 그대로 구현한 영상)

## 0. 먼저 읽을 것
### 용어와 변환
| 표기 | 뜻 | 변환 |
|---|---|---|
| `t` | 타임라인 시간 (완성본 0~20초) | `f = t × 24` |
| `c` | 클립 시간 (생성된 5초 클립 안) | `t = c + offset` |
| 오프셋 | C1: **1.5** · C2: **5.5** · C3: **8.5** · C4: **11.5** | 모든 클립은 **앞뒤 0.5초 여유(핸들)**를 두고 생성한다. 사용 구간은 `c0.5` 이후 |

### 이 문서가 전제하는 것
- **쓰는 도구는 정해지지 않았다.** 그래서 도구 이름이 아닌 일반 기능(시작 프레임 지정, 끝 프레임 지정, 모션 강도, 카메라 고정, 네거티브 프롬프트)만 말한다. 쓰시는 도구에 없는 항목은 건너뛴다.
- 클립 C1, C4는 **기준 이미지 `source/mia_base_A.png`와 같은 구도**(카메라 고정)로 만든다.
- 편집 단계에서 푸시인과 질감을 입히므로, **모델에게 카메라 움직임을 시키지 않는다.**
- 소리는 `audio/`에 이미 있다. 이 문서의 소리 동기 표시는 그 타임라인과 같다.

## 3. 연기 설계 (모든 클립 공통)
### 시선 벡터 (화면 기준)
| 이름 | 방향 | 쓰는 곳 |
|---|---|---|
| **중립** | 화면 **오른쪽**, 아주 약간 **아래** (정적 CRT를 봄). 오른쪽 약 15°, 아래 약 5~8° | 기본 상태. 기준 이미지 그대로 |
| **램프** | 화면 **왼쪽 위**. 위 약 35°, 왼쪽 약 15~20° (램프는 눈의 왼쪽 위에 있다) | C1의 A3 동작 |
| **창** | 화면 **왼쪽**, 약간 위. 왼쪽 약 25°, 위 약 10° | C4의 B2 동작 |
**카메라 렌즈를 보는 시선은 만들지 않는다.** 시선이 이동할 때도 중립 → 창으로 갈 때는 **렌즈 높이보다 위로 호를 그리며** 지나간다. (렌즈와 눈이 마주치는 프레임이 생기면 그 클립은 탈락)

### 신체 움직임 한계 (1080×1920 기준)
| 부위 | 한계 |
|---|---|
| 머리 회전 | **3° 이하** |
| 머리 이동 | 6px 이하 |
| 어깨 (숨) | 오르내림 2~4px, 주기 약 4초 |
| 눈 깜빡임 | **느리게, 총 0.25초 (6프레임)**. 클립당 1~2회 |
| 입 | **완전히 닫힌 상태 유지.** 움직임이 있으면 탈락 |
| 머리카락 | 아주 미세하게. 바람 없음 |
| 손 | 클립 C1·C2·C4에는 **손이 보이지 않는다** |

### 조명 연속성
- **왼쪽**: 호박색 램프 광(고정). **오른쪽**: 녹색 CRT 광이 얼굴 오른쪽에 닿고 **약 ±6% 깜빡인다** (4초에 2~3번, 불규칙하게).
- 클립 간 색온도가 튀면 편집에서 보정한다. 기준 이미지의 색을 목표로 한다.

```

Keep the face, hair, headset, jumpsuit, lighting, background and framing identical. The red light is lit. Mouth closed. Vertical 9:16.
```

## 5. 클립별 설계
각 클립은 **세 단계 프롬프트**를 준다. **A(한 문단)부터 시도**하고, 비트가 어긋나면 B(시간표 프롬프트), 키프레임을 지원하면 C(키프레임 방식)를 쓴다.

### 공통 생성 설정 (지원하는 항목만)
| 항목 | 값 |
|---|---|
| 비율 | 9:16 세로 |
| 길이 | 5초 (최소 길이가 더 길면 그대로 두고 앞 5초만 사용) |
| 해상도 | 가능한 최고. 1080×1920 미만이면 편집에서 올린다 |
| 프레임레이트 | 24fps (선택 가능한 경우) |
| 카메라 | **고정 / 움직임 없음** |
| 모션 강도 | **낮음** (10 중 2~3) |
| 후보 수 | C1·C4 **8개**, C2·C3 **6개** |
| 시드 | 마음에 드는 후보의 시드를 고정하고 프롬프트만 바꿔 변주 |

### 색과 질감
- **보정 순서**: 클립 간 노출·색 맞춤 → 푸시인 → 글리치 → **테이프 질감** → 오버레이 → 사운드
- **테이프 질감**은 영상 레이어에만 건다. 오버레이에는 걸지 않는다. `tools/tape_look.sh` 기본값(RGB 분리 3px, 스캔라인 10%, 그레인 11~16)에서 시작한다.
- **글리치 레시피**: 가로 띠 7~9개(높이 18~150px)를 ±130px 이동 + R/B 채널을 ±7px 어긋나게 3프레임. 세 번만 쓴다: `f0–9`(전원 인가. 애니매틱은 글리치 대신 오버레이·점의 플리커로 처리했다), `f264–266`, `f439–441`.
- 노출: C3(데크)는 다른 클립보다 **−0.3EV**로 약간 어둡게. 방에 불이 거의 없는 느낌을 유지한다.

## 7. 후보 검수 (`tools/review_clip.py`)
후보를 6~8개 뽑았다면, 눈으로 훑기 전에 **숫자로 먼저 거른다.**
```bash
python3 production/tools/review_clip.py candidate_03.mp4 --offset 1.5      # C1은 1.5, C2는 5.5, C3는 8.5, C4는 11.5
```
**질감 필터를 걸기 전의 원본 클립**으로 돌려야 정확하다. 결과물:
| 출력 | 읽는 법 |
|---|---|
| `sheet.png` | 0.5초마다 한 프레임. 시선과 자세의 흐름을 한눈에 |
| `metrics.png` | 얼굴 drift, 입 움직임, 눈 부위 움직임, REC 램프 (기대 스케줄 음영 포함) |
| 표준 출력 | 평균/최대값, **눈 움직임 피크 시각**, 램프 전환 시각, 램프 스케줄 일치율 |

**고르는 순서**
1. **입 움직임**이 후보 중 높은 것을 먼저 버린다 (말하는 클립).
2. **얼굴 drift**가 높은 것을 버린다 (다른 사람이 되어 감).
3. **눈 움직임 피크**가 비트 시트의 시각(C1: `c1.8–2.3`, C4: `c1.5–2.4`)과 가까운 것을 남긴다.
4. 남은 후보를 `sheet.png`로 보고 시선 방향·렌즈 응시 여부를 눈으로 확인한다.
5. 최종 후보를 실제로 재생해서 **합격 기준**을 확인한다.
※ 이 숫자들은 **후보끼리 비교하는 용도**다. 절대 기준값은 없다. (애니매틱의 정지 이미지에서 얼굴 drift 평균이 약 7%였지만, 이는 질감 필터와 디졸브 영향도 받은 값이다.)
※ C1·C4처럼 **카메라가 고정된 클립**에만 의미가 있다. C2·C3는 `sheet.png`로 눈으로 본다.
