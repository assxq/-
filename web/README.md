# 낡은 미래 — 웹페이지 (Station 7)

빌드 도구 없이 `index.html` 한 파일로 동작하는 정적 페이지다. (외부 의존: Google Fonts의 VT323 / Allerta Stencil / Caveat. 없어도 시스템 서체로 대체됨. Station 7 도상 스프라이트는 파일 안에 인라인으로 들어 있다)

## 실행
- 파일을 브라우저로 열면 된다. 또는 `npx http-server web` 등으로 서버를 띄운다.
- 배포: GitHub Pages(저장소 설정 → Pages → 폴더 `/web`), Netlify, Cloudflare Pages 모두 그대로 올라간다.

## 퍼즐 흐름 (처음 온 사람 기준)
1. 책상 위 **카세트**를 누르면 플레이어에 들어간다.
2. 라벨의 **점과 선(모스 부호)**이 `0 2 7`이다.
3. 카운터를 **027**에 맞춘다. (FF/REW는 짧게 누르면 1씩, 길게 누르면 감김. 카운터 옆 버튼은 0으로 되돌림)
4. 그 자리에서 **PLAY**. 다른 위치에서는 `NO SIGNAL`.
5. 테이프에 기록된 로그가 재생되고, 끝나면 **채널 링크**가 LCD에 나타난다. 이후 방문 시에는 바로 링크가 보인다.

막힌 사람을 위한 힌트는 말이 아니라 **연출**로 나온다: 60초 후 라벨의 잉크가 깜빡이고, 120초 후 카운터가 맥동하고, 200초 후 LCD에 `CODE: MORSE`가 뜬다.

## 설정 (`index.html` 상단의 `CONFIG`)
| 항목 | 설명 |
|---|---|
| `code` | 정답 숫자. 바꾸면 라벨의 모스 부호가 자동으로 바뀐다. |
| `links.instagram` / `links.youtube` | 계정 주소. **비어 있으면 `PENDING`으로 표시**되므로 계정 확정 후 채운다. |
| `hintAfterSec` | 힌트가 나오는 시간(초) |
| `tapeEnd` | 테이프 길이(카운터 최댓값) |

## 테스트용
- `?reset` 을 주소 끝에 붙이면 "이미 푼 사람" 기록을 지우고 처음 상태로 시작한다.
- 브라우저 콘솔에서 `__oldfuture.S` 로 내부 상태를 볼 수 있다.

## 세계관 규칙 준수 메모
- 화면 속 문구는 모두 **테이프에 기록된 로그**이며 방문자를 부르는 문장을 쓰지 않는다.
- 그날의 내용·지워짐 등 비공개 정답은 담지 않았다. (공개 가능한 S1 정보만: 27번째, 연락 두절, 배터리, 날짜 가려짐)
- 사운드는 모두 브라우저에서 합성한다. 오디오 파일 없음. 우측 상단 `SND`로 끈다.
- 선반의 칸은 27개이고 마지막 칸만 비어 있다. (정답을 눈치채는 사람을 위한 보조 단서)

## 산업적 사용감 (v1.1)
- **서체**: 브랜드와 키 라벨은 스텐실, 손글씨 메모는 Caveat, LCD는 VT323
- **장비 질감**: 세로로 흘러내린 얼룩과 먼지, 경고 줄무늬, 뒤로 늘어진 케이블
- **마스킹 테이프 메모**: `BATT. CHECK DAILY`, `LOG EVERYTHING` (단서 장부 C003, C004 계열의 보강)
- **LCD 상단 상태 아이콘** (`icons/` 도상): 로그가 한 줄씩 나올 때 해당 아이콘이 켜진다. 테이프 삽입 = 테이프, SIGNAL FOUND = 신호, `NO CONTACT` = 연락 두절(적색), `BATTERY` = 배터리, `DATE` = 가려진 날짜(앰버). 이미 푼 방문자에게는 처음부터 모두 켜져 있다.
- **키 아이콘**: 재생·정지·되감기·빨리감기·꺼내기는 Station 7 조작 아이콘을 쓴다.
- **책상 위 획 27개**: 오방점(五) 형태로 그은 흰 마커 자국. 해석이 열려 있다 (담당관 번호 / 날짜 / 송신 횟수). 단서 장부 C011.
