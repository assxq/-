# 낡은 미래 — 웹페이지 (Station 7)

빌드 도구 없이 `index.html` 한 파일로 동작하는 정적 페이지다. (외부 의존: Google Fonts의 VT323 / Allerta Stencil / Caveat. 없어도 시스템 서체로 대체됨. Station 7 도상 스프라이트는 파일 안에 인라인으로 들어 있다)

## 실행
- 파일을 브라우저로 열면 된다. 또는 `npx http-server web` 등으로 서버를 띄운다.
- 배포: GitHub Pages(저장소 설정 → Pages → 폴더 `/web`), Netlify, Cloudflare Pages 모두 그대로 올라간다.

## 퍼즐 흐름 (처음 온 사람 기준)
1. 책상 위 **카세트**를 누르면 플레이어에 들어간다.
2. 라벨의 **점과 선(모스 부호)**이 `0 2 7`이다.
3. 카운터를 **027**에 맞춘다. (FF/REW는 짧게 누르면 1씩, 길게 누르면 감김. 카운터 옆 버튼은 0으로 되돌림)
4. 그 자리에서 **PLAY**. 다른 위치에서는 `NO SIGNAL`.
5. 테이프에 기록된 로그가 재생되고, 끝나면 **채널 링크**가 LCD에 나타난다. 이후 방문 시에는 바로 링크가 보인다.

막힌 사람을 위한 힌트는 말이 아니라 **연출**로 나온다: 60초 후 라벨의 잉크가 깜빡이고, 120초 후 카운터가 맥동하고, 200초 후 LCD에 `CODE: MORSE`가 뜬다.

## 설정 (`index.html` 상단의 `CONFIG`)
| 항목 | 설명 |
|---|---|
| `code` | 정답 숫자. 바꾸면 라벨의 모스 부호가 자동으로 바뀐다. |
| `links.instagram` / `links.youtube` | 계정 주소. **비어 있으면 `PENDING`으로 표시**되므로 계정 확정 후 채운다. |
| `hintAfterSec` | 힌트가 나오는 시간(초) |
| `tapeEnd` | 테이프 길이(카운터 최댓값) |
| `codeB` | SIDE B 정답 (기본 `'62'`, 카운터 062). B면 라벨의 모스 부호가 자동으로 바뀐다. |
| `storageKeyB` | SIDE B 완료 저장 키 (기본 `oldfuture.solvedB.v1`) |
| `hintAfterSecB` | SIDE B 힌트 시간(초), 기본 `[60, 120, 200]` |

## 테스트용
- `?reset` 을 주소 끝에 붙이면 "이미 푼 사람" 기록을 지우고 처음 상태로 시작한다.
- 브라우저 콘솔에서 `__oldfuture.S` 로 내부 상태를 볼 수 있다.

## 세계관 규칙 준수 메모
- 화면 속 문구는 모두 **테이프에 기록된 로그**이며 방문자를 부르는 문장을 쓰지 않는다.
- 비공개 설정은 담지 않았다. (공개 가능한 S1 정보만: 27번째, 연락 두절, 배터리, 날짜 가려짐, 시간은 `PLAYING`)
- 사운드는 모두 브라우저에서 합성한다. 오디오 파일 없음. 우측 상단 `SND`로 끈다.
- 선반의 칸은 27개이고 마지막 칸만 비어 있다. (정답을 눈치채는 사람을 위한 보조 단서)

## 산업적 사용감 (v1.1)
- **서체**: 브랜드와 키 라벨은 스텐실, 손글씨 메모는 Caveat, LCD는 VT323
- **장비 질감**: 세로로 흘러내린 얼룩과 먼지, 경고 줄무늬, 뒤로 늘어진 케이블
- **마스킹 테이프 메모**: `BATT. CHECK DAILY`, `LOG EVERYTHING` (단서 장부 C003, C004 계열의 보강)
- **LCD 상단 상태 아이콘** (`icons/` 도상): 로그가 한 줄씩 나올 때 해당 아이콘이 켜진다. 테이프 삽입 = 테이프, SIGNAL FOUND = 신호, `NO CONTACT` = 연락 두절(적색), `BATTERY` = 배터리, `DATE` = 가려진 날짜(앰버). 이미 푼 방문자에게는 처음부터 모두 켜져 있다.
- **키 아이콘**: 재생·정지·되감기·빨리감기·꺼내기는 Station 7 조작 아이콘을 쓴다.
- **책상 위 획 27개**: 오방점(五) 형태로 그은 흰 마커 자국. 해석이 열려 있다 (담당관 번호 / 날짜 / 송신 횟수). 단서 장부 C011.

## 2단계: SIDE B (선택, 1단계를 푼 뒤에만)
**퍼즐 사슬**
1. 1단계를 푼 뒤(또는 이미 푼 방문자는 처음부터) 플레이어에서 테이프를 **EJECT**로 꺼낸다. (테이프가 이미 책상 위에 있으면 그대로)
2. 책상 위 테이프의 **라벨 윗부분(STATION 7 / SIDE A 줄)**을 누르면 테이프가 뒤집혀 **SIDE B** 라벨이 나온다. 라벨 아래쪽(모스 부호·릴 창)을 누르면 지금까지처럼 삽입된다. 다시 위쪽을 누르면 A면으로 돌아온다. (뒤집을 때 카운터는 000)
3. B면 라벨의 모스 부호는 **6 2** (`-.... ..---`). 정답은 카운터 **062**. 삽입 후 062에서 PLAY. (027은 B면에서 `NO SIGNAL`)
4. 짧은 로그가 재생된다: `SIDE B` / `NO ENTRIES` / `BATTERY: 61%` / `TIME: PLAYING` / `END OF TAPE`, 이어서 `SIDE B LOGGED`와 링크. 1단계의 `BATTERY: 62%`에서 1이 줄어 있다.
5. 완료 시 `localStorage` 키 `oldfuture.solvedB.v1` = `1`. 1단계 보상(링크, 27번 칸)은 그대로이며 2단계와 무관하게 먼저 나타난다. `?reset`은 두 키를 모두 지운다.

**단서 출처 (모두 화면 안, 언어 무관)**: B면 라벨의 모스 부호(주 단서) / 1단계 로그의 `BATTERY: 62%`와 LCD 배터리 아이콘(확인) / 3자리 카운터 / 1단계에서 익힌 "라벨 모스 = 카운터 숫자" 규칙. 선반 27칸·책상 위 27획·`OPERATORS 001-026`은 26/27로 읽히는 **미끼**이며, B면에서 카운터를 026에 두고 PLAY하면 `NO CONTACT`만 나온다.

**힌트 (말 없음, 마지막 진행 후 N초; 진행 = 삽입/꺼냄/뒤집기)**
| 상황 | 60초 | 120초 | 200초 |
|---|---|---|---|
| 테이프가 밖, A면 | `SIDE A` 글자가 깜빡 | (유지) | (유지) |
| 테이프가 안, A면 | EJECT 키가 맥동 | (유지) | (유지) |
| B면 (밖/안) | B 라벨 모스 잉크가 깜빡 | (삽입 상태) 카운터 + 배터리 아이콘 맥동 | (삽입 상태) LCD에 `CODE: MORSE` |

LCD 상단에 B면이 삽입되면 네모 `B` 표시가 켜진다(네모 = 상태). 완료한 방문자는 `TIME` 아이콘이 켜진 채로 시작한다.

## 모바일 세로 (폭 600px 이하 + portrait)
- 가로 760 데스크를 0.47배로 줄이는 대신, **400 x 1262 세로 적층 배치**(베이 → LCD → 카운터/VU → 키 → 책상의 테이프·선반·획)로 바꿔 약 0.9배로 보여 준다. 페이지는 세로 스크롤. 케이블 장식과 노브는 이 모드에서 숨긴다.
- 터치 기기(`pointer: coarse`)에서는 투명 패딩으로 키·리셋 버튼·SND의 터치 영역이 현재 배율 기준 약 44 CSS px 이상이 된다(`--s` 변수 사용). 데스크톱은 그대로.

## 접근성
- LCD의 타이핑 글자는 보조기기에서 숨기고(`aria-hidden`), **한 줄이 완성될 때마다** `#srLog`(`role=log`, polite)에 한 번씩만 옮긴다. 링크는 LCD에서 그대로 포커스 가능.
- 키보드: 모든 키·카세트·뒤집기·SND·리셋 버튼 동작. FF/REW는 Enter/Space 짧게 = 1칸, 길게 = 감김(포커스를 잃으면 멈춤). 선반 27칸은 탭 정지점 1개 + 방향키 이동. 삽입된 카세트는 탭 순서에서 빠진다.
- `prefers-reduced-motion`: 그레인·깜빡임·둥실·먼지·커서 점멸·전환·힌트 애니메이션을 끄고 힌트는 정지된 글로우로 표시.

## 자동 테스트
`/tmp` 아래 Playwright 스크립트로 1·2단계 전체 플레이를 데스크톱(1280x800)과 모바일(390x844)에서 검증했다. 저장소에는 포함하지 않았다.
