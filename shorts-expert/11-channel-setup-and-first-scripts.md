# 채널 세팅 & 첫 5개 스크립트

> 채널명은 후보일 뿐, 사용 전 YouTube/TikTok/Instagram 핸들과 상표 중복을 직접 확인할 것. 특정 AI 브랜드명(GPT, Claude 등)은 채널명에 넣지 않는 것을 권장(상표/오인 리스크).

## 1. 채널명 후보 (영어, 짧고 기억 쉬움)
| 후보 | 컨셉 |
|---|---|
| **AI in 60** | 60초 AI 시연 |
| **Tool Test Daily** | 매일 툴 테스트 결과 |
| **Prompt Lab** | 프롬프트 실험 |
| **Shortcut AI** | 시간 절약 AI 워크플로 |
| **Tried It Today** | "직접 해봄" 신뢰 포지셔닝 (오리지널 가치와 정책 안전에 유리) |
- 추천: **Tried It Today** 또는 **AI in 60** — 포맷이 곧 브랜드가 되고 직접 해본 결과를 보여주는 방향과 일치

## 2. 채널 소개 (복붙용)
```
I test AI tools so you don't waste your time.
60-second demos, real results, no hype.
New video every day.
Business: [email]
```

## 3. 업로드 메타데이터 템플릿
- 제목: `[결과] in [시간] with free AI` 형식, 60자 이내 (예: `I summarized a 50-page PDF in 20 seconds (free AI)`)
- 설명 1줄: 영상 요약 + 키워드 + "Full tutorial: [링크]" + 제휴 표기(`Affiliate link — I may earn a commission`)
- 해시태그: #AI #AItools #productivity (3개 이내)
- 고정 댓글: 질문 하나("What should I test next?") → 양방향 대화 신호
- 업로드 시간: 미국 동부 기준 오전 7~9시 / 저녁 6~8시 두 구간 테스트

## 4. 첫 5개 스크립트 (각 30~45초)
형식: `[0~2s 훅] / [전개] / [페이오프+루프]` — 화면녹화 + 본인 목소리, 큰 자막

### #1 긴 PDF 요약 (포맷 A)
- **훅(0~2s)**: 화면에 50쪽 PDF + 타이머 "00:20". 자막/음성: "This free AI read 50 pages in 20 seconds."
- **전개**: ①PDF 업로드 화면 ②프롬프트 "Summarize into 5 bullets and list 3 risks" 보여주기 ③결과 스크롤 ④"Then I asked: what's on page 37?" → 정확한 답
- **페이오프**: "It got page 37 right. But check the numbers — here's where it slipped." (실제 틀린 부분 1개 공개 = 신뢰)
- **엔딩/루프**: "Next: what happens if you upload a contract?" → 첫 프레임(타이머)으로 연결
- 자막 문구: `50 pages → 20 sec` / `Ask follow-ups` / `Always verify numbers`

### #2 3시간 리서치 vs 5분 (포맷 B)
- **훅**: 분할화면 좌 "3 hours" 우 "5 min". "Same research. 3 hours vs 5 minutes."
- **전개**: 수동(탭 20개 이미지 빨리감기) vs AI(질문→출처 포함 요약) → 결과물 나란히
- **페이오프**: "AI was faster, but it missed one source. Here's my 30-second check."
- **CTA**: "Comment 'RESEARCH' and I'll post my exact prompt."

### #3 프롬프트 공개: 계약서 쉬운 말로 (포맷 C)
- **훅**: 결과 먼저 — 복잡한 약관 문장 → 쉬운 문장. "Legal jargon → plain English in 5 seconds."
- **전개**: 프롬프트 전체 화면 표시 `Explain this clause like I'm 15. Flag anything that costs me money.`
- **페이오프**: "Not legal advice — but it tells you what to ask a lawyer." (면책 자막 필수)
- **참고**: 법률/의료/금융 조언 단정 금지, 면책 표시

### #4 이번 주 AI 뉴스 3가지 (포맷 D)
- **훅**: "3 AI updates this week that actually change your workflow."
- **전개**: 각 10초: 뭐가 나왔나 → 누가 쓰나 → 직접 해본 결과 한 컷
- **주의**: 업로드 직전 공식 발표/제품 페이지에서 사실 확인, 출처 화면 캡처 삽입
- **루프**: "Number 3 surprised me" → 마지막에 3번 결과를 첫 프레임에도 1초 노출

### #5 무료 AI 챗봇 5개 같은 질문 테스트 (포맷 E)
- **훅**: 5개 로고 + 같은 질문. "Same question. 5 AIs. Only 1 got it right."
- **전개**: 질문 1개(검증 가능한 답, 예: 날짜 계산+논리), 각 5초 결과 → 정답 여부 ✅/❌
- **페이오프**: 승자 공개 + 이유 한 줄 + "I'll retest next month."
- **참고**: 제품명은 사실 비교 목적으로 표시, 결과는 실제 테스트 기록 보관(캡처)

## 5. 제작 체크리스트 (영상마다)
- [ ] 첫 1초에 결과/숫자/타이머
- [ ] 실제로 돌려본 화면(편집으로 가짜 결과 만들지 않기)
- [ ] 틀린 점/한계 1개 솔직하게 → 신뢰·정책 안전
- [ ] 무음 가독성(큰 자막), 안전영역
- [ ] 면책/제휴 표기
- [ ] 개인정보·비공개 문서 화면 노출 금지
- [ ] 설명란 현지 키워드

## 6. 영어 스크립트 작성 팁
- 문장은 짧게(초등 6~8학년 수준), 숫자와 동사 중심
- 직접 녹음 후 AI/번역기로 문법 교정만 받기(음성 자체를 AI로 대체하지 않기)
- 한국어 억양은 문제 아님 — 자막 정확도가 더 중요
