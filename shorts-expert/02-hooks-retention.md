# 훅 & 리텐션

## 구조 템플릿
`훅(0~2s) → 약속/맥락(2~5s) → 전개(오픈루프 10~15s마다) → 페이오프 → 루프 엔딩/CTA`

## 훅 유형
| 유형 | 예 |
|---|---|
| 결과 선공개 | 완성본/충격 장면을 첫 프레임에 |
| 질문/호기심 갭 | "Why does X never Y?" |
| 반직관 주장 | "Stop doing X if you want Y" |
| 숫자/구체성 | "3 mistakes costing you $500" |
| 패턴 인터럽트 | 급줌, 컷, 효과음, 시각적 이상 요소 |
| 직접 호명 | "If you're a beginner at X..." |

## 리텐션 장치
- 빠른 컷, 5~8초 내 시각 변화
- 오픈 루프: "마지막에 반전 있음" → 마지막에 해소
- **루프 엔딩**: 마지막 프레임이 첫 프레임으로 자연 연결 → 재시청
- 항상 자막(큰 글씨, 안전 영역 지킴), 무음 기준 제작
- 오디오: 트렌딩 사운드는 보조, 내용이 주

## 길이 (가이드)
- 15~30초: 반응/밈/단일 아이디어, 재시청 유리
- 45~60초: 설명형
- 90~120초: 딥다이브 (주제·타겟 인내심 맞을 때)
- 원칙: **필요한 만큼만**. 늘리지 말고 완주율로 판단.

## 개선 루프
YouTube Studio → 쇼츠 → "Viewed vs Swiped away" + 리텐션 그래프 → 급락 지점 편집 → 다음 영상에 반영. 10~20개 단위로 패턴 분석.
