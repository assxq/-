# 채널 플레이북

## Phase 0 — 포지셔닝 (1주)
- 니치 1개, 타깃 국가/언어 1개, 수익 경로(롱폼/제휴/상품) 정의
- 경쟁 채널 20개·아웃라이어 50개 분석

## Phase 1 — 검증 (2~4주)
- 하루 1~2개, 총 30~50개. 훅 유형·길이 A/B
- 지표: 스와이프 이탈률 <30%, APV 80%↑ 목표(니치별 상이), 공유율
- 승자 포맷 상위 20% 식별

## Phase 2 — 스케일 (2개월~)
- 승자 포맷 시리즈화 (단, 변주 필수 — 정책 리스크 회피)
- 쇼츠→롱폼 연결 (고정 댓글, 관련 영상 링크)
- 다국어 오디오 추가
- 크로스포스팅: Shorts / TikTok / Reels 각각 네이티브 업로드(워터마크 X)

## Phase 3 — 수익화
- YPP 진입 + 제휴·스폰서·상품
- 월간 리뷰: 시청자 지역, RPM, 수익원 비중

## 영상별 체크리스트
- [ ] 첫 1초에 시각/텍스트 훅
- [ ] 무음 가독성(자막)
- [ ] 오픈루프 / 루프 엔딩
- [ ] 고유 가치 1개 이상
- [ ] 제목·설명·해시태그 현지 키워드
- [ ] 공유하고 싶은 이유(sends) 1개
